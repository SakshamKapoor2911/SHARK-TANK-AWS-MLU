# Shark Tank App-Build Challenge: Event Overview & Context

## 1. Event Background

- **Title**: Cloud Connect — Howard 2026: Shark Tank App-Build Challenge
- **Sponsors & Organizers**: AWS (Amazon Web Services), Amazon MLU (Machine Learning University), BEN Tech (Black Employee Network Tech), Howard University
- **Dates**: Monday, September 21 – Tuesday, September 22, 2026
- **Locations**: Howard University (Washington, D.C.) & Amazon HQ2 (Arlington, VA)
- **Target Audience**: College students (undergraduate & graduate across disciplines; no prior coding experience required)

---

## 2. Challenge Mechanics & Flow

### Team Dynamics
- **Team Size**: ~10 students per team.
- **Identity**: Each team picks an official Startup / Team Name.
- **Challenge Selection**: Teams pick or are assigned 1 of the 5 student life scenarios.

### Time & Build Sprint
- **Build Sprint Window**: 60–75 minutes total.
- **Philosophy**: Rapid prototyping from plain-English description to a functioning interactive web app.
- **Core Loop**: Prompt $\rightarrow$ Inspect Result $\rightarrow$ Refine Prompt $\rightarrow$ Add Features / Tone / Connections.

### Tooling Environment
1. **Primary Tool**: **Amazon Quick**
   - **Recommended Path**: `Apps` mode (describe your app in plain English, and Quick generates a working web application with UI elements, inputs, and generative AI features).
   - **Alternative Path**: `Chat` mode.
2. **Fallback Tool**: **PartyRock** (AWS Bedrock-powered generative AI app builder playground).

---

## 3. Presentation & Judging Structure

### Phase 1: Breakout Room Pitches
- **Pitch Duration**: ~2 minutes per team.
- **Pitch Contents**:
  1. Team Name & Problem Statement (hook).
  2. Target Student Persona.
  3. What the App Does (Core Value Proposition & standout features).
  4. *Note*: No live code demo strictly required, but having a working interactive prototype to show or reference gives a competitive edge.
- **Room Voting**:
  - Each team gets **one vote** for a *different* team (no self-voting).
  - Highest vote tally is crowned the **Breakout Room Champion**.

### Phase 2: Main-Stage Finals
- The Room Champions advance to the main stage.
- Present directly to head judges (executives and leaders from AWS, MLU, and Howard University) for the overall Shark Tank championship.

---

## 4. Competitive Success Levers

To win breakout rooms and the main-stage final, teams must excel in four distinct areas:

1. **Relatability & Empathy**: Does the solution directly hit an acute student pain point (e.g., ramen diet, exam panic, broke budget, freshman loneliness, mental burnout)?
2. **Prompt Engineering & Feature Polish**: Did the team satisfy all 3 core requirements and successfully unlock 1+ stretch goals (e.g., image generation, adaptive difficulty, budget projections)?
3. **User Experience & Tone**: Is the conversational/UI tone engaging, non-judgmental, collegiate, and intuitive?
4. **2-Minute Pitch Delivery**: Can the team deliver a crisp elevator pitch that commands attention, explains the architecture/logic clearly, and addresses real student impact?
